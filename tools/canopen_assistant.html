伺服上线流程（DS402）
1. 写 0x06 → 0x6040  Shutdown
2. 写 0x07 → 0x6040  Switch On
3. 写 0x0F → 0x6040  Enable Operation
4. 写 0x6060 设置运行模式（PP=1, PV=3, CSP=8…）

NMT 状态机
Pre-Operational ─[0x01]→ Operational
Operational ─[0x02]→ Stopped
Operational ─[0x80]→ Pre-Operational
Stopped ─[0x80]→ Pre-Operational
任意状态 ─[0x81]→ Initialisation → Pre-Op
任意状态 ─[0x82]→ Comm Reset → Pre-Op
COB-ID 固定为 0x000，DLC = 2。节点 ID 填 0x00 为广播，无需 SDO 握手，驱动器直接执行。
