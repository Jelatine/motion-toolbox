机器人 DH 三维建模

编辑连杆参数，探索关节运动与末端位姿。

三维场景

拖动旋转 · 滚轮缩放 · Shift / 右键拖动平移X 红Y 绿Z 蓝虚线：关节运动轴

关节运动

拖动滑块或输入 q。播放时，各关节在设定上下限之间往复运动。

DH 参数表

θ₀、d₀ 是固定偏置；旋转关节 θ = θ₀ + q，平移关节 d = d₀ + q。q 及上下限使用对应的角度或长度单位。单位切换保留物理尺寸和姿态。

切换 SDH / MDH 会使用当前数值按新约定重新建模，不会自动转换为同一机器人。示例按钮会替换当前参数。

末端位置 · 基坐标系

末端齐次变换矩阵 T₀ₙ

旋转部分无量纲，最后一列平移使用当前长度单位。

建模与显示说明

MDH 使用 Craig 约定，参数为 aᵢ₋₁、αᵢ₋₁、dᵢ、θᵢ；SDH 参数为 aᵢ、αᵢ、dᵢ、θᵢ。三维连杆为 DH 变换路径的示意，不代表实际机械外形。F0 为基坐标系，Fn 为末端坐标系，J 为关节；旋转轴以圆形、平移轴以方形标记。支持最多 20 个关节。公式参考 Robotics Toolbox DHLink。
