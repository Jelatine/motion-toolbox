公式说明
三段式梯形曲线：加速段 → 匀速段 → 减速段
当距离不足以达到 v_max 时，自动降格为三角形曲线（无匀速段），峰值速度为 v_peak = √(a·d + (v0²+v1²)/2)

加速时间：t_acc = (v_peak − v0) / a   减速时间：t_dec = (v_peak − v1) / a
匀速时间：t_const = (d − d_acc − d_dec) / v_peak

7 段明细
段名称Jerk持续时间末速度末加速度
公式说明
S 曲线将加速过程分为 7 段：加加速 → 匀加速 → 减加速 → 匀速 → 加减速 → 匀减速 → 减减速
Jerk 限制（段 1,3,5,7）：T_j = a_max / J
匀加速段（段 2）：T_a = (v_max/a_max) − T_j（若 < 0 则 a_max 降格）
匀速段（段 4）：T_v = d/v_max − v_max/a_max − T_j（若 < 0 则 v_max 降格）

速度衔接说明
过点速度处理：若用户指定过点速度，段终/段始速度取该值；若留空，系统自动计算最大可行过点速度（基于减速/加速距离对称约束），使相邻段平滑衔接。
