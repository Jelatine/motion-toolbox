# 运动控制工具集 (Motion Toolbox)

一套面向运动控制和机器人工程师的在线工具集，涵盖轨迹规划、电机参数换算和 CANopen 通信辅助，无需安装，直接在浏览器中使用。

## 工具列表

### 1. 轨迹规划器

提供三种运动规划算法：

- **梯形速度曲线** — 加速 / 匀速 / 减速三段规划，距离不足时自动退化为三角形曲线
- **S 曲线（7 段式）** — 带 Jerk（加加速度）限制的平滑运动曲线，减少机械冲击
- **多段经由点规划** — 经由多个路点平滑过渡，自动优化中间点速度，支持手动覆盖

输出包括各阶段时间表和实时绘制的位置 / 速度 / 加速度曲线。

### 2. 脉冲 ↔ 关节位置换算器

针对步进电机 / 伺服电机的参数换算工具，支持配置：

- 减速比、编码器分辨率（PPR）、方向极性
- 零点脉冲偏置与零点角度偏置

提供脉冲 → 角度和角度 → 脉冲的双向换算，附带完整计算公式。

### 3. CANopen 通信辅助工具

DS402 伺服协议与 CANopen 通信的全套调试辅助，包含四个功能标签：

| 标签 | 功能 |
|------|------|
| SDO 报文生成器 | 自动计算 COB-ID，生成带颜色标注的字节级报文，一键复制 |
| 对象字典 | 收录 60+ 条标准对象（通信参数 0x1xxx / DS402 设备参数 0x6xxx），支持搜索筛选，点击自动填入 SDO 生成器 |
| 控制字 / 状态字分析 | 位级交互分析，附 DS402 状态机模拟（6 状态转移、故障注入、审计日志） |
| NMT 报文生成器 | 生成节点启动 / 停止 / 复位等网络管理报文 |

### 4. 关节减速比校正

输入当前减速比、运控反馈角度和实测角度，计算机械臂关节校准后的减速比，同时显示角度误差与减速比修正百分比。页面会校验零值、无效减速比以及反馈与实测角度方向不一致等情况。

计算公式：`校准后减速比 = 当前减速比 × 运控反馈角度 ÷ 实测角度`

### 5. 关节零点偏移计算

输入各关节当前 angle_offset 与同一物理位置的两组角度，计算要设置的新 angle_offset，支持 1–12 个关节、整列粘贴和一键复制结果。

- **更换驱动板**：换板前记录角度，换板后输入当前角度；更新后新板在同一位置显示换板前的角度。
- **示教点与墙面平行**：输入原示教点角度和手动调平后的当前角度；更新后执行原示教点即到达平行位置（该关节所有示教点会同步平移）。

计算公式：`新 angle_offset = 当前 angle_offset + (目标角度 − 当前角度)`，由运控换算 `angle = (pulse − offset) / (PPR × N) × 360° × dir + angle_offset` 推得。

### 6. 机器人 DH 三维建模

- 支持标准 DH（SDH）和 Craig 改进 DH（MDH），默认 **MDH、角度、毫米**。
- 编辑各关节的 a、α、d₀、θ₀、类型及运动上下限，支持添加和删除关节。
- 旋转轴使用 θ = θ₀ + q，平移轴使用 d = d₀ + q；滑块、数值输入和往复播放实时驱动三维模型。
- 支持角度 / 弧度、米 / 毫米切换，自动换算参数和关节范围，保持物理姿态。
- 三维场景支持旋转、缩放、平移、适应模型，显示坐标系、关节轴和末端齐次变换矩阵。
- SDH / MDH 切换按新约定解释当前参数，不是同一机器人参数的自动转换。页面内附有公式和混合关节示例。
- 无外部依赖，直接打开 `tools/robot_dh_modeler.html` 即可离线使用。

## 快速开始

无需安装任何依赖，直接用浏览器打开即可：

```
index.html
```

或在项目根目录启动本地静态服务（任意方式均可）：

```bash
# Python
python -m http.server 8080

# Node.js (npx)
npx serve .
```

然后访问 `http://localhost:8080`。

## 项目结构

```
motion_toolbox/
├── index.html                   # 工具导航首页
└── tools/
    ├── trajectory_planner.html  # 轨迹规划器
    ├── pulse_joint_converter.html  # 脉冲 / 关节换算器
    ├── canopen_assistant.html   # CANopen 通信辅助
    ├── joint_gear_ratio_calibrator.html  # 关节减速比校正
    ├── joint_angle_offset_calculator.html  # 关节零点偏移计算
    ├── joint_angle_offset_math.js  # angle_offset 计算与列表解析
    ├── robot_dh_modeler.html    # 机器人 DH 三维建模
    ├── robot_dh_modeler.js      # 参数交互、关节运动与三维绘制
    └── robot_dh_math.js         # SDH / MDH 正运动学
```
